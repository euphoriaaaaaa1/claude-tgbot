① Telegram bot token …

没有它 bot 收发不了消息。
怎么拿：Telegram 里搜 @BotFather → 发 /newbot → 起个名字、再起个以 bot 结尾的用户名 → 它回你一串形如 123456789:AAxxxxxxxx 的东西，整串就是 token。
填哪：~/.claude/channels/<bot>/.env 的 TELEGRAM_BOT_TOKEN=

② 你的 Telegram user_id …

白名单空着，bot 收到消息也不理。
怎么拿：Telegram 里搜 @userinfobot，随便发它一句，它回你的 Id: 一串数字（不是 @用户名）。
填哪：~/.claude/channels/<bot>/access.json 的 allowFrom 数组

③ DeepSeek API key …

缺它私聊照样能跑，但情绪分、关系数值、群聊导演、主动消息都不工作。
怎么拿：浏览器开 platform.deepseek.com → 注册/登录 → 左侧 API keys → 创建 → 复制形如 sk-xxxx 的 key。
填哪：configs/_global.yml 的 jiwen.delta_llm.api_key
